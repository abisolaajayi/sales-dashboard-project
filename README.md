# 📊 Sales Dashboard Project

## 📌 Overview
This project is an interactive sales analysis dashboard built using Power BI. It analyzes sales performance across regions, categories, customer segments, and shipping modes.

## 🛠 Tools Used
- Excel (Data Cleaning & Preparation)
- Power BI (Data Visualization & Dashboarding)
- GitHub (Version Control & Portfolio)

## Key Insights
- Identified top-performing regions and cities
- Analyzed sales trends over time
- Evaluated product category performance
- Explored customer segment behavior
- Reviewed shipping mode distribution

## Dashboard Features
- KPI cards (Total Sales, Orders, Customers)
- Sales trend over time
- Sales by region and category
- Top 10 cities analysis
- Interactive slicers (Region, Category, Segment, Ship Mode)
